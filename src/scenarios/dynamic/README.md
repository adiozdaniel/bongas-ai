# 🌈 Dynamic Scenarios: JSONB Pipelines

> **Extensible, database-defined recommendation workflows.**

The Dynamic Scenario module provides an execution engine for recommendations defined as JSONB pipelines in the database. This enables high-velocity changes to recommendation logic without requiring a full application re-deployment.

---

## 🏗️ Architecture

- **`Stages`**: A comprehensive collection of pluggable recommendation components (filters, boosters, diversifiers).
