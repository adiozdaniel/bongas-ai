# 🎯 Boost: Engagement

Adjusts item scores based on historical interaction patterns (CTR, View Through Rate). High-engagement items are given priority in the ranking.

---

## ⚙️ Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `engagement_weight` | float | 1.5 | Multiplier for engagement signals. |
