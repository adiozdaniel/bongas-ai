# 🛡️ Pipeline Stages: Filter

> **Hard constraints to ensure safety, availability, and relevance.**

Filter stages remove items from the stream that do not meet specific criteria.

---

## 🧩 Sub-Modules

| Stage | Description |
| :--- | :--- |
| **Availability** | Removes items that are no longer active or licensed. |
| **Maturity** | Enforces age-rating constraints based on user profile. |
| **Language** | Filters content based on user's preferred or spoken languages. |
| **Already Watched** | Excludes items the user has already consumed. |
