# 🧠 Pipeline Stages: ML

> **Deep inference for high-fidelity ranking and scoring.**

ML stages use specialized runtimes (ONNX, PyTorch) and vector databases for complex neural inference tasks.

---

## 🧩 Sub-Modules

| Stage | Description |
| :--- | :--- |
| **ONNX Inference** | General-purpose ranker using a neural network. |
| **Similarity** | Embedding-based similarity calculation for reranking. |
| **BERT4Rec** | Transformer-based sequence inference. |
| **Heuristic Aggregator** | Blends multiple model outputs into a unified score. |
