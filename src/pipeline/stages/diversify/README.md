# 🌈 Pipeline Stages: Diversify

> **Counter-balancing relevance with variety to improve long-term user satisfaction.**

Diversification stages prevent the recommendation list from being dominated by a single category, creator, or style.

---

## 🧩 Sub-Modules

| Stage | Description |
| :--- | :--- |
| **MMR** | Maximal Marginal Relevance for balancing relevance and diversity. |
| **Genre Diversity** | Penalizes consecutive items from the same genre. |
| **Creator Diversity** | Ensures a mix of different content creators in the top results. |
| **Serendipity** | Injects high-quality items from outside the user's usual profile. |
