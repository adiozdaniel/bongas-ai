# 🌈 Pipeline Stages: Diversify

> **Counter-balancing relevance with variety to improve long-term user satisfaction.**

Diversification stages prevent the recommendation list from being dominated by a single category, creator, or style.

---

## 🧩 Sub-Modules

| Stage | Description |
| :--- | :--- |
| [**🎯 MMR**](./diversify_mmr/README.md) | Maximal Marginal Relevance for balancing relevance and diversity. |
| [**🎼 Genres**](./diversify_genres/README.md) | Penalizes consecutive items from the same genre. |
| [**👨‍🎨 Creator**](./diversify_by_creator/README.md) | Ensures a mix of different content creators in the top results. |
| [**📅 Release Year**](./diversify_by_release_year/README.md) | Diversifies the list across different publication eras. |
| [**✨ Serendipity**](./serendipity/README.md) | Injects high-quality items from outside the user's usual profile. |
