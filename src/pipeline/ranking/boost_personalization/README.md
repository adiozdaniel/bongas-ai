# 👤 Boost: Personalization

The core personalization stage. It calculates a dynamic boost based on the cosine similarity between the user's latent embedding and the item's features.

---

## ⚙️ Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `sensitivity` | float | 1.0 | Controls the "steepness" of the personalization curve. |
