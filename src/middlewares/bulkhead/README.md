# 🧱 Middleware: Bulkhead

> **Resource Isolation and Concurrency Control.**

The Bulkhead middleware limits the number of concurrent requests to a specific endpoint or service. By "partitioning" resources, it ensures that a slowdown in one part of the system doesn't consume all available threads/connections, leaving the rest of the system responsive.
