# 🗣️ Search: Analyzer

> **Localized linguistic understanding for Sheng and Swahili.**

Provides specialized tokenization and analysis for East African dialects. By using `jieba-rs`, the analyzer can correctly segment mixed-language queries, ensuring cultural relevance in search results.

## 🛠️ Components

- **ShengTokenizer:** Custom Tantivy tokenizer wrapping Jieba.
- **ShengAnalyzer:** Full analysis pipeline including Lowercasing and specialized segmentation.
