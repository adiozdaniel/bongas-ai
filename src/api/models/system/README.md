# ⚙️ API Models: System

Internal operational models for reporting system health, monitoring metrics, and security status. Used primarily by administrative and monitoring endpoints.

---

## 🏗️ Model Inventory

| Type | Description |
| :--- | :--- |
| **HealthResponse** | Overall system uptime and version status. |
| **CacheStatsResponse** | Multi-tier hit/miss rates and efficiency. |
| **KafkaHealthResponse** | Consumer lag and connectivity status. |
| **SecurityStatusResponse** | Binary integrity and license validation. |
