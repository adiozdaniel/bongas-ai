# 🎨 Candle Architectures

This module defines the native Rust model structures for the Sovereign Training Pillar.

## 🏗️ Models

### 1. `StudentRankingHead`
A 3-layer Multi-Layer Perceptron (MLP) designed to take pre-extracted content DNA (512D) and output engagement scores.

### 2. `StudentSequenceHead`
A native adaptation of the sequencing logic for session-aware predictions.
